# Multi-Quiz Engine 🌟

A premium, high-contrast, high-difficulty quiz interface built to challenge core frontend engineering principles. This engine rejects standard blue-heavy SaaS design trends in favor of a customized **"Cyber-Gold"** glassmorphic aesthetic.

🚀 **Live Demo:** [ayushtriescode.github.io/Multi-Quiz-Engine/](https://ayushtriescode.github.io/Multi-Quiz-Engine/)

---

## ✨ Features

- **Cyber-Gold Architecture:** Built using a true dark-zinc foundation (`#020617` / `#09090b`) with premium amber and fuchsia accents.
- **Glassmorphism Design:** Containers utilize `backdrop-blur-xl`, low-opacity borders, and custom inner elevations to create high-end visual depth.
- **Dynamic Feedback Engine:** Answer buttons respond instantly to states, glowing **Emerald** for success or **Rose** for errors.
- **Smart Navigation:** Features progressive question tracking, custom navigation logic, and responsive layouts scaling flawlessly from mobile to ultra-wide displays.
- **Micro-interactions:** Fine-tuned button states using `active:scale-95` and smooth transitions to give the application a native, desktop-app feel.

---

## 🛠️ Tech Stack & Concepts Explored

- **React (v18+)**: State management via `useState`, conditional rendering architecture, and clean prop-drilling patterns.
- **Tailwind CSS v4**: Deep-dive into utility-first design, arbitrary values `[]`, hover/disabled states, fluid layout wrappers, and custom radial gradients.
- **Component Lifecycle**: Managed component mounting/unmounting patterns to automatically reset the simulation state upon re-initialization.

---

## 📸 Interface Preview

- **Initialize State:** Sleek onboarding card featuring a technical overview and ranking metrics.
- **Simulation State:** The dynamic assessment interface with progress indicators and status locks.
- **Finalize State:** Accuracy mapping rendering direct performance diagnostics.
